# Multimedia & Application — BCA429CO

A responsive, searchable course companion for the BCA429CO Multimedia and Application syllabus.

## Included
- Twelve unit-based study sections
- Search across unit descriptions, topics and glossary
- Light/dark theme and responsive navigation
- Exam preparation and marks distribution
- Five practical/laboratory guides
- Essential glossary and print-friendly layout

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for the Pages deployment to finish. The expected URL is:
   https://thagunnaharish1-netizen.github.io/multimedia-and-application/

## Local preview
Open `index.html` in a modern browser. No build step or package installation is required.
